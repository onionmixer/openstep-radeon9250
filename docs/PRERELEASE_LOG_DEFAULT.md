# 출시 전 항목 — 제출 로그가 기본으로 켜져 있다 (설계 노트, 아직 안 함)

## 1. 크기

M2d 의 실측(run 790191988, 부팅 `00a7424d`):

| 팔 | 고정비 us/제출 | 로그 |
|---|---:|---|
| `t-accel` | 1575 | **켬** |
| `t-stage` | 492 | 끔(`quiet 5000`) |
| `t-bothoff` | 211 | 끔 |

**로그 하나가 제출당 1,083 us 다.** 지금까지 이 사다리가 깎아 온 것 전부(491 → 211,
−280 us)보다 **네 배 크다.** 그리고 그것은 기본값이다 — `quiet` 를 아무도 안 내면
클라이언트가 그대로 낸다.

로그값은 고정도 아니다: 같은 부팅에서 syslogd 가 포화되기 전 1,441, 뒤 1,087
(docs/M2D_PLAN.md 2-3a, [[measurement-discipline]]).

## 2. 왜 아직 안 하나

**이 사다리가 그 로그로 측정한다.** 기본을 끄면 `judge_m1l` 의 짝, `check_cp`,
`check_r5d`, M1q 격자의 `(stage, wait)` 짝이 전부 눈이 먼다.  M2c 가 계측기를 껐을 때는
`tdump` 라는 **대체 출구**가 이미 있었지만, 제출 로그에는 그런 것이 없다.

## 3. 어디를 건드려야 하나 — 먼저 읽은 것

| 자리 | |
|---|---|
| `OSRDNDisplay.m:1308` | **유일한 호출** — `quiet = osrdn_cp_quiet_take(&rdnCp);` 이고, 그 아래 한 제출의 모든 줄이 이 하나의 값으로 갈린다 |
| c5c1c36f 판 osrdn_cp.m 2476-2486행 | `osrdn_cp_quiet_take` — 리스를 하나 깎고, 0 이 되면 **스스로 말하기 시작한다** |
| `osrdn_cp.m:2940-2951` | `cpQuiet` — `lease != 0` 이면 켜고, 0 이면 지금 말한다 |
| `osrdn_cp.h:98` | 그 설계의 근거: "도구가 중간에 죽어도 머신이 **영원히 조용한 채** 남지 않는다" |

`quiet` 가 리스인 것은 **조용함이 위험한 상태**라는 전제 위에 있다.  기본을 뒤집으면
그 전제가 뒤집힌다 — 위험한 상태는 **시끄러움**(제출당 1 ms)이 되고, 리스는 엉뚱한
쪽에 걸려 있게 된다.

## 4. 그래서 모양은 이것이어야 한다

**리스를 뒤집는다**: 기본은 조용하고, `CP_OP_LOUD <lease>` 가 **N 번 말하고 저절로
조용해진다**.  같은 안전 성질이 그대로 산다 — 도구가 죽어도 머신이 영원히 시끄럽지 않다.

    오늘                          출시 전
    기본: 말한다                  기본: 조용하다
    quiet N: N 번 삼키고 돌아온다  loud N: N 번 말하고 조용해진다

**`quiet` 는 지우지 않고 남긴다** — 그것을 부르는 팔·검사기가 여럿이고, 기본이 조용하면
`quiet N` 은 무해한 no-op 이 된다.  다만 `quiet 0`("지금 말하라")은 **`loud` 로 옮겨야**
하고, 그 자리가 러너에 여럿 있다.

## 5. 이 변경이 깨뜨리는 것 — 세기 전에는 하지 말 것

- 러너의 모든 `quiet 0` 은 "로그 다시 켜기" 를 뜻한다.  기계로 세어 전부 `loud` 로.
- `judge_m1l` 의 `read_drv`·`sentwords`·`tstage` 는 로그가 **있어야** 한다.  그 팔들이
  `loud` 를 내는지 `check_run_m1l` 같은 검사기로 강제.
- `check_cp`/`check_r5d` 의 절차 대조는 연산 줄을 센다.
- **부팅 첫 줄**: 지금은 드라이버가 스스로 말한다.  조용한 기본에서도 `RDN-R5 keys`·
  `RDN-R2B` 계열은 계속 나와야 한다 — 삼켜지는 것은 **제출 경로**뿐이다
  (`OSRDNDisplay.m:1308` 아래의 줄들).

## 6. 언제

**M2e 의 실기 확인이 끝난 뒤.**  기본값을 한 번에 둘 뒤집으면 어느 쪽이 무엇을 했는지
못 가른다 — M2d 가 잔차 8 us 를 놓고 자 둘을 들이댄 것과 같은 이유다
([[measurement-discipline]]).
