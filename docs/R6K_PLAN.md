# R6k — 시저 칸 마무리: 보조 시저 세 사각형과 부분 지우기 (계획, 코딩 전, codex 교차검토 대상, 2026-09-21)

사다리(`PLAN.md` R6 5)의 다음 칸은 **시저**다.  주 시저(`RE_TOP_LEFT`/`RE_WIDTH_HEIGHT`)는 R6b 에서 끝났다.
남은 것은 **보조 시저**(`RE_AUX_SCISSOR_CNTL` + `RE_SCISSOR_TL/BR_0..2`)와, 시저가 **깊이 지우기·깊이 쓰기**에
어떻게 걸리는지다.

## 0. 한 줄 요약

세 개의 보조 사각형은 **어느 참고에서도 켜지지 않는다**(전부 0 으로 쓴다) — 뜻도, 좌표 배치도, 결합 방식도 문서가 없다.
`FILTER_ROUND_MODE` 와 같은 자리다: 우리가 처음 잰다.  이름 붙인 규칙 공간 513 개(191 동치류)로 한 부팅에서 가른다.
동시에 **시저로 자른 부분 지우기**가 되는지(드라이버가 곧 쓸 동작)와 **잘린 화소가 깊이를 갱신하는지**를 같은 부팅에서 잰다.

## 2. 재는 것

**A. 보조 시저의 뜻** — 이름 붙인 규칙 공간(아래 3).
**B. 보조 시저가 쓰기 영역을 **넓힐 수 있는가**(검증기 안전 질문): 기하가 주 시저보다 클 때, 보조 사각형을 크게 켜도
쓰기가 주 시저 밖으로 나가지 않아야 한다.  나가면 검증기는 0x26f0·0x1cd8–0x1cec 를 **금지**한다.
**D. 잘린 화소의 깊이**: 시저로 잘린 화소가 깊이 버퍼를 갱신하는가(래스터 단계에서 버려지면 갱신 없음).
**E. 뒤집힌 사각형**(BR < TL): 아무것도 안 그리는가, 전부 그리는가 — 주 시저·보조 시저 각각.

## 3. 이름 붙인 규칙 공간 (보조 시저)

한 사각형이 만드는 집합을 `R(TL, BR)`, 화소 집합을 다음 축으로 이름 붙인다.

| 축 | 값 |
|---|---|
| 좌표 배치 | `x_low`(= 주 시저처럼 `x \| y<<16`, **F12 가 문서로 뒷받침**) · `y_low`(뒤바뀜 — 그래도 재서 확인한다) |
| 끝 | `br_incl`(BR 포함) · `br_excl`(BR 미포함) |
| 극성 | `keep`(EXCLUSIVE=0 이면 사각형 **안**만 남긴다) · `drop`(EXCLUSIVE=0 이면 사각형 **안**을 버린다) — EXCLUSIVE=1 은 늘 반대 |
| 결합 | `and`(켜진 사각형들의 조건을 모두 만족) · `or`(하나라도 만족) |
| 바이어스 | `b0` · `b1440`(F8 의 R300 바이어스가 R200 에도 있는 경우) |
| 칸 너비(x) | `11` · `ge12`(x 반 워드가 쓰는 비트 수; 우리 값으로는 12 비트와 16 비트를 못 가르므로 **“11 이냐 12 이상이냐”**까지만 주장한다) |
| 칸 너비(y) | `11` · `ge12`(축마다 다를 수 있다 — Y10) |
| 부호 | `unsigned` · `signed`(칸이 11 비트일 때만 보인다; 16 비트면 음수 구간에 우리 값이 닿지 않는다) |
| 관문 | `free`(보조 시저는 `RE_CNTL` 비트 1 과 무관) · `gated`(비트 1 이 꺼지면 보조 시저도 안 문다) — F11 이 부른 축 |
| 무효 | `none`(RV280 에서 이 레지스터들은 아무 일도 안 한다) |

2⁹ + 1 = **513 개**.  `build/r6k/design2.py` 로 계산한 결과 계획한 경우들에서 **191 동치류**로 갈린다.
남는 묶음은 전부 물리적 한계다 — 사각형이 지도 밖으로 나가는 조합에서는 끝·배치·너비가 **보이지 않고**,
16 비트 칸에서는 부호가 안 보이며, 아무것도 안 자르는 조합에서는 `free`/`gated` 가 안 보인다.
**그럴 법한 답은 모두 크기 2 의 동치류**에 떨어지고, 그 짝은 “16 비트 칸의 부호” 하나뿐이다(볼 수 없는 축).
`none` 은 혼자 있는다.  같은 그림을 주는 규칙은 **한 동치류로 보고하고 크기를 적는다**(R6i-2·R6j 규약).

## 4. 경우 (한 부팅, 경우 번호 146–160)

**안전 논거는 기하에 있다**(보조 시저가 뺄셈만 한다는 가정에 기대지 않는다 — 그게 바로 AS7 로 재는 것이다):
래스터라이저는 원시 **안**의 화소만 만들고, 모든 경우의 기하는 색 버퍼(64×64, `CP_R6_PITCH` 64·`CP_R6_BUF_WORDS`
4096, `osrdn_cp.h` 159–160) 안에 있다.  AS0–AS6·AS8–AS14 는 32×32 지도 안, AS7 만 [0,40)² 로 지도보다 크되 버퍼 안이다.
따라서 어느 가설이 맞든 쓰기는 우리 창 안이고, 지도 밖 워드는 이미 있는 다이제스트(`cpR6Digest`, 버퍼 전체 4096 워드)가 센다.
사각형은 일부러 **비대칭**(x ≠ y)으로 잡아 좌표 배치를 가른다: R0 = TL(6,3) BR(20,13), R1 = TL(10,8) BR(26,24),
R2 = TL(2,18) BR(14,29).

| 이름 | 켠 사각형 | 무엇을 가르나 |
|---|---|---|
| AS0 | 없음(대조) | 기준 그림 — 지도 1024 화소가 전부 칠해진다 |
| AS1 | R0, `EXCLUSIVE_0`=0 | 극성·배치·끝(10 그림) |
| AS2 | R0, `EXCLUSIVE_0`=1 | 극성(EXCLUSIVE 가 뒤집는지) |
| AS3 | R0+R1, 둘 다 0 | `and`/`or`(18 그림) |
| AS4 | R0(0) + R1(1) | 섞은 극성(18 그림) |
| AS5 | R2 만 | 세 번째 칸도 같은가 |
| AS6 | 뒤집힌 사각형 TL(20,13) BR(6,3) | E — 빈 사각형인가 |
| AS7 | 버퍼 전체 사각형, 기하가 주 시저보다 큼 | **B(안전)** — 지도 밖 워드가 하나도 변하면 안 된다 |
| AS8 | R0, 깊이 쓰기 켬 | D — 잘린 화소가 깊이를 갱신하는가 |
| AS9 | R0 에 **+1440** 한 사각형 | 바이어스(b1440 이면 AS1 과 같은 그림) |
| AS10 | R0 의 **x 에만 +2048** | x 칸 너비(11 이면 AS1 과 같은 그림) |
| AS13 | R0 의 **y 에만 +2048** | y 칸 너비 — 축마다 다를 수 있다(Y10) |
| AS14 | TL = (2048−16, 2048−16), BR = (20,13) | 부호(음수면 [0,20]×[0,13], 부호 없으면 TL>BR 이라 빈 사각형) |
| AS11 | 주 시저 뒤집기(TL > BR, `SCISSOR_ENABLE`) | E(주 시저 쪽) |
| AS12 | **AS1 과 똑같되 `RE_CNTL` = 0**(주 시저 `SCISSOR_ENABLE` 끔) | **관문**(F11) — 보조 시저가 비트 1 에 매여 있는가 |

AS0–AS11·AS13·AS14 는 `RE_CNTL` = 2(`SCISSOR_ENABLE`, 주 시저 TL = (0,0) 이라 효과 없음), AS12 만 0 이다.

**C(부분 지우기)는 경우를 두지 않는다 — R6b 가 이미 쟀다**: 경우 C 가 클립 [0,37)×[0,21) 로 깊이 쓰기를
그 안으로 제한했다(`docs/R6B_PLAN.md` 15·88 행).  선례 경로가 깊이 지우기 그 자체이므로 “주 시저로 자른
부분 지우기”는 측정된 사실이고, 여기서 다시 잴 것은 **보조 시저** 쪽(AS8)뿐이다.

## 5. 절차·게이트

**한 부팅**: 준비(`record`·`rec3d`·`load`·`map`·`reset`·`start`·`rec3d`) → F(회귀, 경우 6) → AS0–AS14 →
`rec3d`·`stop`·`record`·cycle.  ZCLEAR 16 회, PLANE 12 회(깊이 경우 AS8 만).
실행 `build/r6k/run_r6k.sh <boot>`(`plan_ops.txt`), 준비와 F 는 `build/r6k/r5op.sh <op> [len]` 으로 하나씩.
판정 `check_r6a.py <log> --boot N --build <stamp> --procedure r6k`.
- 게이트 K1(AS0 기준 그림) · K2(보조 시저 규칙 이름 — 공간 밖이면 FAIL(측정) 후 호스트 분석) ·
  K3(넓히지 못함: 지도 밖 워드 0) · K4(잘린 화소의 깊이) · K5(뒤집힌 사각형 둘).
- 부정 시험: 화소 하나 옮김, 지도 밖 워드 하나, 규칙을 다른 이름으로 읽기, 경우표·스트림 변이.

## 6. 교차검토에 물을 것 (한 호출 한 주장)

1. 보조 시저를 켜는 데 `AUX_SCISSOR_CNTL` 과 TL/BR 말고 더 필요한 레지스터·비트가 있는가(예: `RE_CNTL` 의 다른 비트).
2. 보조 시저 좌표가 주 시저와 같은 배치·같은 끝 규칙이라는 근거가 트리 어디에 있는가(없으면 "없다"로 답할 것).
3. 이 설계가 놓치는 것(특히 공간 밖 가설).
