## 0. 한 줄 요약

R6c 의 색 경로(블렌드 0 단계 통과·PK_RGBA·순서 비트)를 **그대로** 두고, 원시만 `RECT_LIST` → **`TRIANGLES`** 로 바꾼다.  삼각형이 어떤 픽셀을 덮는지
(표본점·경계 동점·정점 스냅) 는 **참고 어디에도 없으므로** 가설 48 개를 오라클로 계산해 두고, 가설을 모두 가르는 삼각형 6 개(T1–T6)의 **덮임 비트맵을
픽셀 전수** 로 되읽어 하나를 가린다.  가린 규칙이 이후 사다리의 오라클이 된다.  구로·깊이 16 비트·검증기는 다음 조각.

## 2. 가설 (오라클, 유리수 산술) — **9·10 절이 대체한다**(가설 4032, 경우 추가, T3·T4 게이트 삭제)

정점을 float32 로 만든 뒤 스냅 → 모서리 함수로 표본점 판정.  48 = 스냅 4 × 표본점 2 × 동점 규칙 6:
- 스냅: 없음 · 1/8 절삭 · 1/8 반올림 · 1/16 절삭 (D1 의 TRUNC·8TH 가 유력)
- 표본점: 픽셀 (x+0.5, y+0.5) · (x, y) (D1 의 OGL 이 유력 — 이름의 뜻은 실측으로)
- 동점(표본점이 모서리 위): 좌상단 · 우상단 · 좌하단 · 우하단 · 전부 포함 · 전부 제외 (메모리 y 가 아래로 증가: "위" = 작은 y)

경우(모두 32×32 안, z 1.0, 컬링 없음 → 감김 무관 예상):

| 경우 | 삼각형 | 가르는 것 |
|---|---|---|
| T1 | (4,4) (28,4) (4,28) | 대각 모서리가 표본점을 지난다(0.5 표본) |
| T2 | T1 + 0.5 | 축 모서리가 표본점을 지난다 |
| T3 | 정사각 (8,8)–(24,24) 을 대각으로 둘, **색 둘** | 공유 모서리의 주인(좌상단 vs 나머지) |
| T4 | T3 + 0.5 | 축 공유 모서리 |
| T5 | (3.3,2.6) (29.45,7.8) (10.1,30.2) | 스냅 |
| T6 | (4.06,3.94) (27.19,6.31) (9.44,28.07) | 스냅(1/16 과 1/8) |
| T7 | T1 의 세 정점에 **서로 다른 색** | 평면 셰이딩의 기준 정점(측정) |
| T1r | T1 의 감김 반대 | 감김 무관 여부(측정) |

python: T1–T6 만으로 **48 가설이 48 무리로 모두 갈린다**(경우별 7–10 무리).  참고 수치(OGL·좌상단·1/8 절삭): T1 276, T2 300, T3 120+136, T4 136+120,
T5 343, T6 273 픽셀.  소수 정점은 float32 로 정확하지 않다(3.3 → 3.2999999523…) — 오라클·드라이버 표 모두 float32 비트가 정본.

## 3. 설계 — **9·10 절이 대체한다**(이 절의 T3·T4 게이트·경우 번호·가설 수는 폐기)

- 드라이버: 경우 표에 **삼각형 경우 9–16**(T1–T7, T1r).  각 경우 = 정점 3 또는 6 개(x, y, 색) 의 정적 표 + 원시 TRIANGLES.  상태는 R6c F 와 같음
  (PP_CNTL 0x1000, PLANEMASK 전부, fmt 0x803, vsc 0x10000, RE_CNTL 2), 가위 = **버퍼 전체** (0,0)–(63,63)(규칙 H, TL 도 적용).
  - 헤더 개수 = 정점×5 (3 정점 0xc00f3500, 6 정점 0xc01e3500), VF = 4|0x30|0x40|(n<<16).  워드: 3 정점 65, 6 정점 80 → **`w[96]`** 로(재측정).
  - A–H 는 **비트 동일**(sim 이 증명).
- 되읽기: 기존 요약 두 벌(깊이·색) + **덮임 지도**: 색 버퍼 32×32 의 각 픽셀을 2 비트로 — 0 패턴 그대로, 1 = 경우의 색1, 2 = 색2, 3 = 그 밖.  1024 픽셀 = 64 워드,
  로그 8 줄(`RDN-R6 cov k w0..w7`).  T7 은 색1 = 마지막 정점 색, 색2 = 첫 정점 색.
- 판정(호스트 `check_r6a.py --procedure r6d`):
  - **안전(모든 경우)**: 표지·블록 나머지 불변·잠금 없음; 색 버퍼 변경 수 = 지도의 비0 수(32×32 밖에 쓴 것 없음); 깊이 요약 = 오라클이 **관측된 덮임**으로 계산한 요약(깊이·색 덮임 일치).
  - A·F: R6c 판정 그대로(회귀).
  - **게이트**: T1–T6 의 지도에 코드 3 없음(색 순수), T3·T4 합집합 = 정사각 256 픽셀·겹침 0(가설 무관 성질), 그리고 **48 가설 중 T1–T6 을 모두 설명하는 것이 있음**
    → 그 이름을 기록(여럿이면 전부).  없으면 FAIL — 경우별 가장 가까운 가설과 다른 픽셀 좌표를 기록(다음 계획의 입력).
  - T7·T1r: 측정(이름 붙여 기록).
- 호스트: 오라클(48 가설·지도·요약), world5 모델(한 가설로 삼각형을 그림 — 판정기가 그것을 찾아내는지), 변이(정점 틀림, 원시 번호, 개수, 색, 지도 코드, 가위 등).

## 4. 실기 절차(한 부팅) — **10 절이 대체한다**
RECORD → REC3D → LOAD → MAP → RESET → START → (ZPREP→ZCLEAR) **A → F → T1 → T2 → T3 → T4 → T5 → T6 → T7 → T1r** → REC3D → STOP → RECORD → cycle.

## 5. 안전
- 모든 정점이 32×32 안, 가위가 두 버퍼 전체라 어떤 오해석도 버퍼 밖에 못 쓴다(규칙 H 실측).
- 새로 켜는 것 없음 — 원시 번호와 정점 수만 다르다.
- 스택: `w[96]`(+96 B, 예상 약 388 B) — reloc 에서 재측정.

## 6. 미룬 것
구로(다음 조각), 깊이 16 비트, PLAN R6 3 항의 커널 제출 검증기(유저 원시를 받는 경로 — 이 단계는 드라이버 안의 고정 원시만), 텍스처.

## 7. 교차검토에 물을 것
1. 가설 공간이 빠뜨린 것(예: 12.4 고정소수·다른 표본 격자, 감김에 따라 달라지는 동점, 가위 경계의 끝 포함).
2. 덮임 지도 설계(32×32·2 비트)가 판정에 충분한가, 커널 쪽 비용·로그 양.
3. 가설이 맞는 것이 없을 때의 FAIL 이 실기에 해가 없는가(측정으로만 남는가).
4. `VF_MAX_VTX_NUM` 9 와 6 정점, 한 패킷 두 삼각형이 안전한가.

## 9. 수정된 설계 (코딩 대상)

- **가설 2016**(8 절 M2) + T1r 용 감김 의존 변형.  판정 = T1–T6·X1–X7 **전부**를 설명하는 가설 묶음(동치류).  남는 동치류는 세 종류로 설명된다(python):
  동점 규칙만 다름(그 표본점에서 동점이 생기지 않음 — "관측 불가" 로 기록), 정확 vs 1/256, 그리고 드문 섞임.  결과 문구는 "**시험한 공간 안에서** 이 동치류".
- 추가 삼각형(float32 비트가 정본):
  X1 (27.375,4.625) (4.3125,3.0625) (10.4375,27.75) · X2 (2.3125,19.3125) (22,7.25) (19.6875,20.4375) · X3 (5.807,6.869) (28.194,13.23) (12.068,21.055) ·
  X4 (29.343,15.937) (4.861,19.402) (29.765,9.319) · X5 (17.587,11.027) (8.799,22.999) (13.408,27.396) · X6 (23.5,10) (18.5,25) (11.0625,3.8125) ·
  X7 (24.46875,3.96875) (21.34375,11.59375) (3.28125,16.71875)(1/32 홀수배 — 1/16 반올림 방식).
- T3·T4: 정사각 a(8,8) b(24,8) c(24,24) d(8,24) → 삼각형 (a,b,d) 색1, (b,c,d) 색2, 각 삼각형의 세 정점은 같은 색.  **게이트 아님** — 동치류 판정에 들어갈 뿐.
- 경우 번호: 9 T1, 10 T2, 11 T3, 12 T4, 13 T5, 14 T6, 15–21 X1–X7, 22 T7, 23 T1r → `CP_R6_CASES` 23.
- 판정:
  - 안전(모든 경우): 표지·블록 나머지 불변·잠금 없음, 색 변경 수 = 지도 비0 수, 깊이 **덮임** = 색 덮임(깊이 변경 수와 오라클이 관측 덮임으로 계산한 자리).  깊이 **값** 은 측정(0xffffff 아니면 이름 붙여 기록).
  - 색 순수: T1–T6·X1–X7 의 지도에 코드 3 없음.
  - **게이트**: 동치류가 비어 있지 않음 → 그 구성원을 기록.  비면 FAIL(측정) — 경우별 가장 가까운 가설과 다른 픽셀.
  - A·F 회귀, T7·T1r 측정.
- 절차: 10 절 확정 설계로 대체.
- 호스트 확인: 모든 경우 `n ≤ 96`, 가위 (0,0)–(63,63), 색 알파 ≠ 0xa5.
