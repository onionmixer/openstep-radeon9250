## 0. 한 줄 요약

R6d 의 삼각형 스트림을 그대로 두고 **`SE_CNTL` 의 확산·알파 셰이딩 필드만 FLAT → GOURAUD** 로 바꾼다.  색 보간의 산술(평가 위치, 속성 설정에 쓰는 정점 위치,
정밀도, 8 비트로의 변환)은 참고에 없으므로 R6d 처럼 **이름 붙은 보간 규칙들**을 오라클로 계산해 두고, 한 번에 한 채널만 기울기를 준 삼각형들의 **32×32 바이트 평면을
픽셀 전수**로 되읽어 가린다.  덮임은 R6d 규칙으로 교차 확인한다.

## 2. 설계

**상태**: R6d 삼각형 경우와 같고 `SE_CNTL` 값 워드(상태 블록 w[15])만 경우별 → G 경우는 **0x48005ade**(확산·알파만 GOURAUD — 스펙큘러·포그는 정점에 없고
포그는 꺼짐, 한 변수만 바꾼다).  `RE_CNTL` 은 2 그대로(원근 끔).

**경우**(모두 32×32 안, 삼각형 안 정점 색이 다름; "상수" = 그 채널이 세 정점에서 같음):

| 경우 | 기하 | 기울기 채널 | 세 정점 값 | 되읽는 채널 |
|---|---|---|---|---|
| G0 | T1 | 없음(세 정점 같은 색) | — | R (평면과 같아야) |
| G1 | T1 | R | 0, 240, 0 (x 방향) | R |
| G2 | T1 | R | 0, 0, 240 (y 방향) | R |
| G3 | X3 | R | 17, 201, 90 | R |
| G4 | X3 | G | 17, 201, 90 | G |
| G5 | X3 | B | 17, 201, 90 | B |
| G6 | X3 | A | 17, 201, 90 | A |
| G7r/g/b/a | T6 | 넷 모두(서로 다른 값) | 네 번 같은 그리기 | R, G, B, A 각각 |

A·F 회귀 포함 ZCLEAR 13 회.

**색 규칙(호스트 검사)**: 패턴 워드는 0xa5000000|i(알파 0xa5, R 바이트 0) — 어떤 픽셀도 패턴과 같아지면 안 보인다.  그래서 모든 경우에서 "알파가 0xa5 가 될 수 없음" 또는
"R 이 0 이 될 수 없음" 중 하나가 성립해야 한다(G6 은 알파가 17–201 을 지나므로 R 을 0 아닌 상수로; G1·G2 는 R 이 0 을 지나므로 알파를 0xa5 아닌 상수로).

**되읽기**: 기존 요약·덮임 지도 + **바이트 평면**: 색 버퍼 32×32 에서 경우의 채널(0 B·1 G·2 R·3 A 의 바이트 자리) 값을 1024 바이트 = 256 워드로, 로그 32 줄
(`RDN-R6 pl<k>`), 그리고 **다른 채널이 경우의 상수와 다른 픽셀 수**(`off`) — 덮인 픽셀에서만.  평면 버퍼는 정적 저장소(상태 구조체, 1 KiB), 스택 불변.

**오라클(보간 규칙 공간, 교차검토로 확정)**: 값 = F(Σ λᵢ·cᵢ), λ 는 표본점에서의 무게중심 좌표.
- 속성 설정 정점 위치: 1/16 절삭(덮임과 같음) · float 그대로
- 평가점: 픽셀 + (k/16, k/16)
- 산술: 정확(유리수) · 기울기 dC/dx, dC/dy 를 2⁻q 로 양자화(q ∈ {8, 10, 12, 14, 16}, 절삭·반올림) 한 평면식을 정점 0 에서 평가
- 변환 F: 내림 · 반올림(half up) · 짝수 반올림 · 올림; 입력 스케일 c(0–255) 그대로 · c·256/255
- 게이트 공간에 넣지 않는 것은 "FAIL 진단 가족" — 단 R6d 교훈대로 **게이트 가설과 진단 가족이 같은 관측을 내는 섞인 동치류가 0 인지 python 으로 확인**하고,
  아니면 가족을 게이트 공간에 합치고 판별 경우를 더한다.

**판정**(`check_r6a.py --procedure r6e`):
- 안전(모든 경우): 표지·블록 나머지 불변·잠금 없음, 색 변경 수 = 덮임 수(32×32 밖 없음), 깊이 덮임 = 색 덮임.
- 덮임 = R6d 규칙(모든 G 경우).
- G0: 모든 덮인 픽셀 = 평면색(구로가 같은 색에서 흐트러지지 않음).
- G1–G6: `off` = 0(다른 채널 불변); G7: 네 평면이 같은 그리기의 다른 채널(반복성 — 덮임·요약 동일).
- **게이트**: 모든 평면을 픽셀 전수로 설명하는 이름 붙은 보간 규칙이 있음 → 동치류 구성원 전부 기록.  없으면 FAIL(측정) — 경우별 최근접 규칙과 최대 오차·오차 픽셀 수.

## 3. 실기 절차(한 부팅)
RECORD → REC3D → LOAD → MAP → RESET → START → REC3D → (ZPREP→ZCLEAR) A → F → G0 → G1 → G2 → G3 → G4 → G5 → G6 → G7r → G7g → G7b → G7a → REC3D → STOP → RECORD → cycle.

## 4. 안전
- 기하는 R6d 에서 이미 그린 T1·X3·T6, 가위 버퍼 전체 — 새 위치 없음.
- 바뀌는 레지스터 값은 `SE_CNTL` 셰이딩 두 필드뿐.
- 로그: 경우당 약 48 줄, 13 회 → 약 600 줄 더(R6d 약 1150 줄 무사).

## 5. 미룬 것
원근 보간(`PERSPECTIVE_ENABLE`, W≠1), 스펙큘러, 디더·`ROUND_ENABLE`, 깊이 16 비트·깊이 보간 값, 텍스처, 커널 제출 검증기.
