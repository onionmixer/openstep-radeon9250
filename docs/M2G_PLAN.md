# M2g — 제출 로그의 기본값을 뒤집는다 (드라이버, 재부팅 필요)

선행: M2f 되돌림 확인(`docs/M2F_PLAN.md` 8), 실기 `c5c1c36f` / 부팅 `01e319b2` 에서
일곱 팔 퍼짐 **2.6 us**.  설계 노트는 `docs/PRERELEASE_LOG_DEFAULT.md`.
**이 문서는 코딩 전에 쓴다.**

## 1. 크기 — 이 칸이 사다리 전체보다 크다

| | 제출당 |
|---|---:|
| 로그 켬(`t-accel`) | **1,573 us** (790250798) — 초판에 1,746 이라 적었다: 판정기의 hold 줄에서 다른 추정치를 옮긴 것이다.  이 표의 다른 줄과 같은 추정치(n=1 낮은 군집)로 고쳤다 |
| 로그만 뺀 것(`t-stage`) | 489 |
| 둘 다 끔(`t-bothoff`) | **190** |

**로그 하나가 1,084 us 다**(초판 1,257 — 위의 오기에서 나온 값).  M2a~M2e 가 깎은 것 전부(489 → 190, −299)의 **네 배**.
그리고 그것은 **기본값**이다 — `quiet` 를 아무도 안 내면 클라이언트가 그대로 낸다.

이 칸은 새로 깎는 것이 아니라 **이미 깎아 둔 것을 기본값으로 주는 것**이다.

## 3. 뒤집기의 모양

**위험한 상태가 뒤바뀐다.**  기본이 조용해지면 영원한 침묵은 더 이상 사고가 아니고,
사고는 **영원한 시끄러움**(제출당 1.25 ms)이 된다.  그러므로 **리스를 `loud` 로 옮긴다**:

    오늘                           M2g
    기본: 말한다                   기본: 조용하다
    quiet N: N 번 삼키고 돌아온다   loud N: N 번 말하고 저절로 조용해진다
    quiet 0: 지금 말하라            (없앤다 — 영원한 시끄러움이 사고이므로)

### 3-1. 새 연산으로 한다, `quiet` 의 뜻을 바꾸지 않는다

`CP_OP_LOUD = 19` 을 **더한다**(`CP_OP_LAST` 18 → 19).  `CP_OP_QUIET` 는 번호도 뜻도
그대로 두고, 기본이 조용하므로 `quiet N` 은 **무해한 no-op** 이 된다.

같은 뜻을 기존 번호에 얹으면 낡은 도구가 **말없이 다른 뜻으로 해석**된다.  이 프로젝트는
이미 그것으로 한 번 태웠다(`build/r7b/r5op.sh` 머리말: 옛 스탬프의 도구가 모든 연산을
조용히 무효로 만들었고 아무것도 "낡았다" 고 말하지 않았다).

### 3-2. 필드

`quiet`/`quietBudget`/`quietSwallowed` 는 **그대로 둔다**(검사기·팔이 읽는다).
`loud`/`loudBudget` 를 더하고, 제출 경로는 **둘 다** 본다:

    말한다  ⟺  loudBudget != 0  이고  quiet 가 아니다

부팅 기본 `loudBudget = 0` → 조용.  `loud N` → `loudBudget = N`.
한 제출이 말할 때마다 `loudBudget--`, 0 이 되면 저절로 조용해진다.
**`loud 0` = 지금 조용해져라**(§4-4 — 남은 예산이 다음 팔로 새지 않게).

### 4-1. 처음 센 23 은 틀렸다

`grep 'quiet [0-9]+'` 로 셌더니 23 이었고 그중 `quiet 491` 둘은 **주석 속 산문**이었다
("t-stage 의 quiet 값 491 us").  주석을 빼고 python 으로 다시 세면 **20** 이다.
계획서 초판의 "`quiet 491` 두 자리가 무엇을 재는가" 는 존재하지 않는 질문이었다.

### 4-2. 로그 켬에 기대는 팔은 여섯이고, 그중 다섯은 **아무것도 말하지 않는다**

러너를 python 으로 따라가 각 팔이 돌 때 리스 상태를 적었다:

| 팔 | 로그 | 어떻게 |
|---|---|---|
| `t-accel`·`t-nobatch`·`t-hold` | 켬 | **기본값에 기댄다 — 아무 연산도 안 낸다** |
| `t-accel2` | 켬 | `quiet 0` 뒤 |
| `t-stock` | (무관) | 소프트웨어 Mesa — `entered=0 submitted=0`, 드라이버에 안 닿는다 |
| `t-poison` | (무관) | 전부 거절 — `entered=91086 submitted=0`, 제출 로그가 없다 |
| 나머지 13 팔 | 끔 | `quiet 5000` 뒤 |

**처음엔 여섯이라고 적었다가 python 으로 `end-tri` 를 읽고 넷으로 고쳤다**(run 790250798).
뒤집으면 그 넷 중 셋은 **말없이 조용해진다.**  러너는 그대로 돌고, 판정기도 그대로 돈다.

### 4-3. 그 다섯이 조용해지면 무엇이 나오나 — **틀린 비용이 조용히**

로그를 **읽는** 곳보다 로그 **값을 재는** 곳이 문제다:

| 짝 | 지금 | 조용해지면 |
|---|---|---|
| `t-accel` 대 `t-stage` | 로그 비용 1,257 us | **≈ 0 us** — "로그는 공짜" |
| `t-accel` 대 `t-hold` | 로그 켠 열고닫기 | 조용한 짝의 복제 |
| `t-accel` 대 `t-accel2` | 로그 켠 표류 | 조용한 표류 |

FAIL 이 아니라 **값**으로 나온다.  이게 이 칸의 주된 위험이다.

빈 로그를 읽는 쪽은 이미 막혀 있다:
- `t-grid.drv` 의 `(stage, wait)` 짝이 없으면 **FAIL**(`judge_m1l.py:325`)
- `sentwords` 는 드라이버 로그가 아니라 **클라이언트 전사**(`RDNTRI ... tri k w0`)를 읽는다
  (`judge_m1l.py:779-786`) — 드라이버 게이트와 무관
- `tstage` 는 게이트 밖(§2)

### 4-4. 그래서 러너에 필요한 것

- 로그 켬 팔 여섯 앞에 **`loud 5000`**, 뒤에 **`loud 0`**.
- **`loud 0` = 지금 조용해져라**가 꼭 있어야 한다.  없으면 한 팔의 남은 예산
  (5000 − 2,167 ≈ 2,833)이 **다음 팔의 첫 2,833 제출을 시끄럽게** 만든다 — 한 팔 안에서
  로그 켬·끔이 섞인다.  오늘의 `quiet 0` 과 대칭이다.
- `quiet 5000`(11) 은 지운다.  `quiet 0`(9) 은 `t-accel2` 앞의 하나만 `loud 5000` 이 되고,
  나머지 여덟은 **지운다**(그 뒤에 로그를 읽는 것은 `tdump` 뿐이고 그것은 게이트 밖).

## 9. 수정된 설계

### 9-1. 조용함은 **제출 한 번의 속성**이고, **claim 안에서만** 산다

새 필드 `subQuiet` 를 `osrdn_mode_cp` 가 **claim 을 쥔 동안에만** 세우고 내린다.
`osrdn_mode_cp` 에 인자 `int quiet` 하나를 더한다:

    if (!modeClaim(mode)) return CP_RC_BUSY;
    ...
    cp->subQuiet = quiet;          /* M2g: 세우는 것도 */
    rc = osrdn_cp_run(...);
    cp->subQuiet = 0;              /*      내리는 것도 claim 안 */
    *copy = *cp;
    modeFinish(mode, base);        /* 여기서 claim 을 놓는다 */

(`osrdn_mode.m:1473-1507`.)  호출자: `r7bSubmit` 은 `quiet` 를, setIntValues(R6 진단)는
**0** 을 넘긴다.  `cpZclear` 의 세 게이트(c5c1c36f 판 osrdn_cp.m 2988행·c5c1c36f 판 osrdn_cp.m 2990행·c5c1c36f 판 osrdn_cp.m 3033행)는
`c->quiet` 대신 `c->subQuiet` 를 본다.

**처음 안(`r7bSubmit` 에서 세우고 내림)은 틀렸다** — §10 의 R2-1·R2-4.

### 9-2. `quiet_take` 의 새 뜻

    if (loudBudget != 0) { loudBudget--; return 0; }   /* 말한다 */
    quietSwallowed++;  return 1;                         /* 기본: 조용 */

- `loud N` → `loudBudget = N`.  `loud 0` → `loudBudget = 0`(지금 조용).
- `quiet N`(어떤 N 이든) → `loudBudget = 0`.  **상호배타**(C7).  옛 `quiet 0` 의 뜻
  ("지금 말하라")은 **일부러 버린다** — 그게 곧 영원한 시끄러움이다.  낡은 호출자는
  §5 의 문턱·셈 검사가 잡는다.
- `c->quiet`·`quietBudget` 는 남긴다(읽는 곳이 있다) — 다만 게이트는 더 이상 안 본다.

### 9-3. 스테이징 실패는 언제나 말한다 (C4)

    if (!quiet || !staged)  IOLog("RDN-R7B stage ... ok=%d")

조용한 성공만 삼키고, 실패는 드물고 증거이므로 말한다(M2f 의 "거절은 말한다" 와 같은 원칙,
이번엔 되돌려지지 않은 형태로).

### 9-4. 러너 — 전수 목록

| 자리 | 지금 | M2g |
|---|---|---|
