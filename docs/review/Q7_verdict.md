# Q7 판정 — R1 코드(probe·파서·시뮬레이터·타깃 스크립트) 교차검토

질문 `Q7_prompt.md`, 회신 `Q7_reply.md` (gpt-5.6-sol, read-only, 2026-09-15).  codex 의 결론은
"첫 실기 실행 차단(BLOCK)".  **codex 가 읽는 도중에 내가 파서를 고치고 있었다**(엄격 문법·중복 검사·
예외 차단·손상 퍼즈).  그래서 파서 항목 일부는 이미 고친 뒤의 코드와 맞지 않는다.  항목마다 **현재
파일**을 다시 읽어 판정했다.

## 결과

`tools/r1/hostcheck.sh` PASS: 파서 자체검사 34, 시뮬레이터 장면 23·변이 13, 타깃 스크립트 빌드 16·실행 12 사례.
각 새 거절 경로는 **그 경로를 지우는 변이 또는 고장 사례가 같은 실행에서 실패함**으로 발동을 증명했다.

## 2차 자기검사

- 1b·1c·1d·5a–5e 는 현재 파일을 열어 결함 문장을 직접 확인한 뒤 고쳤다.
- 1c 의 비트 정의는 codex 인용이 아니라 NetBSD `pcireg.h` 를 새로 받아 읽은 것이다.
- 3a 는 codex 가 옛 파일을 읽었음을 인정하고, 지금 코드에서 남은 부분(거대 `end`, begin/end 위치)만 채택했다.
- 3d·4c 는 codex 결론보다 약하게 채택했고, 이유는 표에 적었다.
- 남는 미확인: cc 2.7.2.1 컴파일, 실제 `IOLog` 손실, CF8 경합의 실제 빈도, 타깃 `ps`·`strings`·`kl_util` 출력 형식.  이것들은 첫 실기 실행이 확인한다.
